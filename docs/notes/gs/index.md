# सामान्य ज्ञान / सामान्य अध्ययन नोट्स

यह TGT और PGT के लिए सामान्य अध्ययन का साझा Notes क्षेत्र है।

## भारतीय इतिहास एवं स्वतंत्रता आंदोलन

[भारतीय इतिहास एवं स्वतंत्रता आंदोलन](history/index.md) के अध्ययन-विषय देखें। यह केवल अध्ययन सामग्री का संगठन है; आधिकारिक पाठ्यक्रम के लिए [सामान्य अध्ययन पाठ्यक्रम](../../syllabus/general-studies.md) देखें।
