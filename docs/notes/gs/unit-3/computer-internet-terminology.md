# कंप्यूटर एवं इंटरनेट शब्दावली

## 1. Basic concept

कंप्यूटर एक electronic device है जो input लेता है, instructions के अनुसार processing करता है, output देता है और data store कर सकता है। **Hardware** physical parts हैं; **software** instructions/programs हैं।

| Term | Full form/अर्थ | आसान उदाहरण/उपयोग |
| --- | --- | --- |
| CPU | Central Processing Unit | processing और control |
| ALU | Arithmetic Logic Unit | गणना और logic |
| RAM | Random Access Memory | temporary working memory |
| ROM | Read Only Memory | स्थायी प्रारंभिक instructions |
| OS | Operating System | hardware और apps के बीच interface |
| Input | data देना | keyboard, mouse |
| Output | परिणाम प्राप्त करना | monitor, printer |
| Storage | data सुरक्षित रखना | SSD, hard disk |
| Hardware | physical parts | keyboard, CPU |
| Software | programs/instructions | browser, word processor |

RAM सामान्यतः volatile होती है; power बंद होने पर उसका working data मिट सकता है।

## 2. Internet terminology

| Term | Full form/अर्थ | आसान अर्थ |
| --- | --- | --- |
| Internet | interconnected networks; कोई single official full form नहीं | दुनिया भर के networks का जाल |
| WWW | World Wide Web | linked web pages की सेवा |
| Website | web pages और resources का संगठित समूह; fixed full form नहीं | किसी संस्था का online site |
| Webpage | website का एक page; fixed full form नहीं | home/about page |
| Browser | web access software; fixed full form नहीं | Chrome, Firefox आदि |
| Search engine | web search service; fixed full form नहीं | Google, Bing आदि |
| URL | Uniform Resource Locator | web address |
| HTTP | HyperText Transfer Protocol | web data transfer protocol |
| HTTPS | HTTP Secure | encrypted web connection |
| Domain | human-readable web name | example.com |
| IP address | Internet Protocol address | network device का address |
| DNS | Domain Name System | domain को IP से जोड़ता है |
| Server | service/data देने वाला computer या program; fixed full form नहीं | website host |
| Client | service माँगने वाला device/app; fixed full form नहीं | browser/user device |
| Cloud | remote internet-based computing; fixed full form नहीं | online storage/service |

## 3. Data और communication

- Download: internet से device पर data लेना।
- Upload: device से server/internet पर data भेजना।
- Email attachment: email के साथ भेजी file।
- Hyperlink: दूसरे page/file तक ले जाने वाला link।
- Bandwidth: data transfer capacity; इसे actual speed के समान न समझें।
- Wi-Fi: wireless local network technology।
- Bluetooth: कम दूरी का wireless device connection।
- Cache: जल्दी access के लिए temporary stored data।
- Cookie: website द्वारा browser में रखी छोटी data file; session/preferences के लिए।

**Email (Electronic Mail):** internet के माध्यम से भेजा गया digital message। **Attachment** उसके साथ भेजी file है। **Hyperlink** दूसरे page/resource तक पहुँचाने वाला clickable link है। **Wi-Fi** wireless local networking technology है; यह कोई universally accepted full form नहीं है। **Bluetooth** कम दूरी के wireless connection का नाम है, standard full form नहीं।

## 4. Security awareness

HTTPS data transmission को encrypt करने में सहायक है, लेकिन यह website की हर जानकारी को automatically सत्य नहीं बनाता। Strong password, multi-factor authentication, software updates, backup और phishing से सावधानी आवश्यक हैं।

## 5. सामान्य confusion

| भ्रम | सही अंतर |
| --- | --- |
| Internet vs WWW | Internet network infrastructure है; WWW उसकी एक service है |
| Browser vs Search engine | Browser pages खोलता है; search engine pages खोजता है |
| RAM vs ROM | RAM working/volatile; ROM comparatively permanent instructions |
| Website vs webpage | Website pages का समूह; webpage एक page |
| Download vs upload | Download प्राप्त करना; upload भेजना |
| HTTP vs HTTPS | HTTPS में secure/encrypted connection का प्रावधान |
| Server vs Client | Server service देता है; client service माँगता/उपयोग करता है |

## 6. परीक्षा में पूछे जाने योग्य तथ्य

- CPU को computer का processing/control center कहा जाता है।
- RAM volatile memory है।
- DNS domain name को IP address से resolve करता है।
- URL किसी resource का address है।
- Browser और search engine अलग हैं।
- Cloud का अर्थ remote computing/storage है, केवल online hard disk नहीं।

## 7. Exam trick

**Input → Processing → Output → Storage** को computer के मूल कार्य-चक्र के रूप में याद रखें।

## 8. Quick revision

कंप्यूटर hardware और software से मिलकर काम करता है। CPU processing करता है, RAM temporary memory और storage long-term data रखता है। Internet network है, WWW web service; browser access tool और search engine खोज service है। URL, DNS, IP और HTTPS web communication के प्रमुख terms हैं।
